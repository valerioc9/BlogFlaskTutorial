# Test BlogFlask

Test de l´aplicaió Proves Unitàries i Proves d´integració
Utilitzem **pytest** que és un amrc de proves amb python que executa tests automàtics. S'han de definir les comprovacions amb *assert*
## Instal·lació

Instal·lar la llibreria pytest dins el nostre .venv

```bash
$ python -m pip install --upgrade pip
$ pip install pytest
$ python -m pip install -e ".[test]" coverage
$ pytest
$ coverage run -m pytest
$ coverage report -m

```
